# 咨询记录、恢复与交付

## 项目位置与保存时机

- 使用当前任务明确指定的项目根；用户未指定时，先从材料和当前工作区核实是否属于同一项目。不能因为 cwd 存在就把无关咨询写进去。
- 项目根仍不明确时，先在对话维护进度，在首次落盘前确定保存位置。优先澄清会影响方案方向的业务问题；位置问题可延后，不必挤占紧接着的一轮。不要默认写进全局技能目录或把源附件目录当作项目根。
- 默认目录为 `docs/socratic-project-manager/<主题>/`。主题使用简短稳定名称，优先复用已有匹配会话。多个匹配会话无法区分时，列出候选请用户选择，不合并不同项目。
- `session.md` 是访谈进度的唯一主记录。其他三份是交付视图，依据此记录更新。文件不是强制执行引擎，也不保证工具之外的后台自动保存。
- 确定保存位置后建立记录；每轮处理回答并形成下一轮入口后写回。中途只创建实际需要的文件，不提前生成空交付物。
- 当前模式或权限不允许写入时，只展示记录草案并注明未保存。写入失败时保留对话摘要、说明失败，不声称存档成功。
- 不把项目数据、完整聊天或个人敏感内容复制进全局技能。记录仅保留决策需要的摘要和来源位置。

## session.md 最小结构

根据项目规模压缩内容，保留以下信息；Markdown 表格或短列表均可。

```markdown
# 项目主题 · 咨询记录

## 当前状态
- 项目根：实际路径
- 目标与范围：当前目标，明确不做的内容
- 阶段、轮次、最后更新：实际值
- 状态：访谈中／阶段性方案／方案交付／用户暂停

## 事实与依据
- 事实或用户自述、来源位置、核实状态；历史诊断单独标记

## 决定
| ID | 内容 | 类型 | 状态 | 用户依据或授权 | 依赖 |
| D001 | 实际决定 | 硬要求／偏好／授权默认 | 已确认／待复核／已取代 | 对应答复与问题编号 | 上游决定 |

## 未决问题与假设
- Q编号：问题、前提、状态（未问／已问未答／已答／延后／不适用）、为何影响方案
- 暂用假设：依据、影响、是否需要确认；不放入已确认决定

## 冲突与变更
- 涉及决定、具体场景、影响、临时处理、待谁裁决；解决后记录答案
- 原决定保留并标记被谁取代；哪些下游决定需要复核

## 下一轮入口
- 本轮已发出的问题编号与必要选项内容
- 下次先处理什么；哪些前提尚未解决

## 交付索引
- 已生成文件及实际状态；尚未生成的不写成链接
```

同一问题追问使用原编号并补充具体情景；新增独立问题使用新编号。依据写实际用户答复或明确授权，不把 agent 的推荐作为用户原话。未答和“不清楚”均保留待解决状态；已授权代拟的答案记录为授权默认。

## 恢复与更新

先读 `session.md` 及已有交付文件，再检查用户本轮消息和相关项目变动。当前明确答复优先于历史记录；出现范围变化时做影响检查。记录不完整时针对缺失项补问，不重做已知问题。只有问题编号而找不到原题时，标记题干缺失，先查已有对话或记录；仍不能恢复再请用户补充，不猜测问题或把答案套到自创题目上。

跨 Codex／Claude Code 使用相同项目文件，不另建每个工具的私有会话副本。保存前读取当前文件，保留别的工具已写入的有效变化；发现相互冲突的并行修改时先合并事实、标记待裁决项，避免整文件覆盖。该约定支持顺序交接，不承诺并行写入事务安全。

仅重新审查改变了前提的决定。简短告诉用户“已恢复到哪一步、保留哪些结论、接着处理什么”，然后处理已有问题的答案或给出下一轮。

## 三份交付物的内容契约

### requirements.md

目标、受众、实际场景；范围与非目标；输入输出；功能或研究需求；硬要求、偏好与授权边界；资源和外部依赖；可验证的验收条目。关键条目链接到决定或事实依据。把未知、假设、未解决冲突放在显眼位置，不藏进附注。

### design.md

存在真实取舍时记录候选方案及比较；记录最终选择与依据。说明流程、职责、必要接口或研究设计、数据与证据流、失败恢复、变更影响、风险及缓解。明确未核实前不能依赖的能力。已有选择不强行新增多个替代方案。

### handoff.md

按依赖排序的实施任务，每项有目的、所需输入、产物、验证方法与完成条件；已知责任角色和资源；必要先行核实；适用的迁移、上线或研究阶段验收；已知限制。末尾列“需求 → 设计落点 → 验收场景”的简表，便于接手者检查遗漏。

不为小任务虚构复杂 API、监控、审批或迁移系统。需求阈值尚未确定就不要编造数值。无法解决的关键取舍标为阻塞并交付阶段性版本；非关键且明确允许的实现自由度单独写清。

交付前核对四份文件的一致性、引用目标存在、无空模板或伪确认。用户要求出稿时可直接交付已满足条件的方案；不要把“文件写好了”说成“用户已验收”。方案交付不自动触发产品实施。
