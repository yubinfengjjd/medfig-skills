# 科研课题：按证据与可行性递进

这里用于规划研究，不据模板替代领域文献、统计判断或机构要求。需要具体医学、统计、伦理规则或最新文献支撑时查可靠原始来源，并区分资料结论与推断。

| 方向 | 通俗切入点 | 应澄清的决定或事实 |
|---|---|---|
| 研究问题 | 你希望知道什么？答案对谁有什么用？ | 可回答的问题、目标人群、应用场景、主要目标 |
| 主张与比较 | 你说“更好”，具体好在哪里、与谁比较？ | 比较对象、主要评价结果、可支持的结论强度 |
| 现有资料 | 数据来自哪里？如何选入？每例有哪些信息？ | 来源、选择过程、缺失、偏差与使用条件 |
| 模型与验证 | 这些病例有没有参与训练、调参或挑选模型？ | 数据独立性、信息泄漏风险、验证设计 |
| 研究设计 | 观察已有资料，还是能增加对照或收集新数据？ | 研究类型、对照、混杂、时间顺序与可行性 |
| 样本与分析 | 哪个结果最重要？现有规模能把它估计得多准确？ | 主要终点、分析单位、不确定性；需要时单独规划样本量论证 |
| 资源与约束 | 可用的病例、合作、设备、预算和时间各是什么？ | 可执行范围、先行核实、数据与审批条件 |
| 证据到图稿 | 每个结论用哪些结果支持？读者如何核对数字？ | 分析、图表、表格、叙述间的对应关系 |
| 失败与验收 | 没发现优势时，这项研究还能回答什么？ | 阴性结果处理、证据边界、研究完成标准 |

先区分用户的目标与数据能支持的事实。小样本、无对照或回顾性数据不能仅凭表述升级为“已证明临床优越”；也不能仅凭样本数武断判定整个研究没有价值。问清能补充什么，再提出探索性研究、补充比较或后续验证等适用路径。

不编造结果、不预设显著性、不保证顶刊接收。具体样本量、统计方法和因果主张必须有研究情境与依据；资料不足就列出核实任务。图表数量、配色、文章结构按本课题确定，不能照搬历史论文的面板配额或期刊偏好。期刊明确规范、用户审美偏好与学习案例分别登记。

研究方案交接应覆盖问题、设计、资料、比较、分析、偏差控制、证据限制、图稿计划、资源与阶段验收。写清哪些工作还只是计划，哪些结果确实已经存在。
