# 医学 SCI Results 写作

依据成图、图例、表格、源数据和作者确认的大纲，撰写或修订正式英文 Results，附逐段中文对照和中英双语小标题。正文只陈述图表支持的结果，突出核心发现，不复述方法、不描述绘图、不过度解读。

## 必读材料（每次起草、修订或续写都执行）

不凭技能名称或上次任务的摘要开始写作。按顺序完整读取：

1. [原始提示词](references/original-results-prompt.md)：基础角色与写作要求。
2. [已确认写作规则](references/writing-rules.md)：对原始提示词的细化，冲突时以它为准。
3. [期刊语言与格式规范](references/journal-style.md)：图号、数值、时态、拼写、篇幅。
4. [判断示例](references/examples.md)：只学判断方式，不迁移具体内容。
5. 项目目录下的 `Results_作者决定.md`（如存在）：已裁决事项直接沿用。

当前用户指令优先于以上材料。

## 工作流程

1. **定位**：读取大纲的 Results 部分，确定本次范围（全部或某节）、各节的分段规划、图表清单和措辞边界。续写时读取已完成节段，确定“下一节”。
2. **读图与图例**：对每个涉及的 Figure，用图像查看工具打开成图 PNG，再读定稿图例和详细图注；对每个 Table 读 md 或 csv。逐 panel 记录：显示了什么、核心结果、关键数字及出处、是主图还是附图、在大纲中属于哪一段（规则第 1、3 节）。
3. **核对数字**：大纲中的每个数字都到表格或源数据中找到对应值，记录出处；发现不一致按规则第 1 节处理并记入核查说明。只在图上有、材料中没有数值的趋势，只作定性描述。
4. **梳理主附图与叙事**：按大纲段落规划，确定每段的核心发现、主图 panel 的次序、附图和表格放在哪一句支持（规则第 2、3 节）。
5. **撰写英文**：默认详细模式；用户要求简洁版时改用简洁模式（规则第 3 节）。每段围绕一个核心发现，按“观测结果 → 关键对比 → 例外或异质性 → 对研究问题的证据边界内含义”展开；核心 panel 的句数随证据量调整，附图两到三句，带过性内容保持简洁；图号附在句末。完整 Results 先写证据骨架，再做一次扩展回查：逐节找出特别发现（方向相反、例外队列、指标排序不一致）和可以回指的前文结果，补进有出处的内容。详细模式英文正文目标 3,500–4,000 词，按各节证据量分配，避免把篇幅平均分给示意 panel 或表格枚举（规则第 3–5 节）。
6. **撰写中文对照**：逐段重组为规范中文，事实、数值、限定和图号与英文一致（规则第 6 节）。
7. **复核**：按下方“交付前检查”逐项确认，再按规则第 8 节决定是否输出核查说明。

默认在当前会话中完成，不派出子代理。

## 项目约定（检测到 PROJECT.md 时）

从工作目录或材料路径向上查找 `PROJECT.md`。找到时按 medpaper-pipeline 的项目目录约定（`medpaper-pipeline/references/project-layout.md`）执行，用户另行指定的路径优先：

- 默认材料：03_outline/ 的大纲、02_figures/out/ 的成图与源数据、04_manuscript/Legends/ 的图注、04_manuscript/Methods/Methods_EN.md。
- 输出到 `04_manuscript/Results/`，文件名固定为 Results_EN.md、Results_ZH.md、Results_EN_ZH.md、Results_核查说明.md，不加项目前缀或版本号。
- 已有同名成稿时，先把旧文件移到 `_archive/<今天日期>/04_manuscript/Results/`，再写新文件；更新 `PROJECT.md` 状态表中 Results 一行（状态 `待确认`、版本、日期）并在变更记录追加一行。
- 作者决定读 `04_manuscript/作者决定.md` 的“通用”和“Results”两节，代替单独的 `Results_作者决定.md`；新裁决追加到“Results”节。
- 审查、盲测、对照稿等过程文件放 `_process/Results/<YYYY-MM-DD>_<描述>/`，不放成稿目录。

没有 `PROJECT.md` 时保持下文原有行为，不新建它。

## 一致性防线（检测到 PROJECT.md 时）

按 `medpaper-pipeline/references/consistency-guards.md` 执行：

- 写作前读项目根的 `口径表.md`：术语用规范名，不用禁用别名；量的定义和关键计数照口径表写。图表标签与规范名不同时，在图注或正文中括注对应（如“目标标签拟合参照（图中 R2 (oracle)）”）。
- 材料冲突按统一权威顺序取舍：代码与回执 > source.json 数值与 definitions > 成图图面 > Methods > 详细图注 > 大纲与规格叙述 > 已写成的下游稿件。本技能其他章节中与此冲突的取舍规定，以此为准。
- 大纲的节标题只是写作意图，不是事实依据。逐队列、逐类别核对数据后，标题只写数据能支持的范围；与大纲标题不一致的，登记为台账“口径”类条目，不再只写在核查说明里。“定稿图例措辞优先”只适用于没有代码或数据可以判定的定性表述。
- 发现冲突时登记到 `_process/冲突台账.md`（写明双方原文、出处、源头阶段和应改的上游文件）。事实类（有代码或数据作证：拟合分区、符号、计数、分组、量的定义、panel 字母）先把被改文件备份到 `_archive/<日期>/`，再直接修改上游文件和已受影响的下游文件，同步口径表；口径类（措辞强弱、结论范围、术语选择）和图面类只登记，等阶段关口由作者裁决。
- 核查说明的“需作者裁决事项”只列台账 ID 和一句摘要；台账中已修复或已裁决的事项不重复上报。
- 交付前依次运行（用 `python -X utf8` 运行脚本（PATH 上的 `python` 若是 Windows 商店空壳，改用真实解释器的完整路径））：`<medpaper-pipeline>/scripts/consistency_check.py <项目根>`（禁用别名与关键计数，命中项修掉或登记），再运行 `<medpaper-pipeline>/scripts/manuscript_check.py results <本稿 EN 文件> --zh <本稿 ZH 文件>`，ERROR 先修掉，WARN 逐条在核查说明中说明（脚本口径见 consistency-guards 第 5 节）。

## 输出

- 每节结构：`## 3.x English subheading` 下一行 `**中文小标题**`；有子节时同样处理 `###`。随后英文段落与中文段落逐段交替（合并稿）。
- 单独保存时，输出到用户指定目录：`Results_EN.md`（纯英文）、`Results_ZH.md`（纯中文）、`Results_EN_ZH.md`（逐段对照）；命中触发项时另附 `Results_核查说明.md`。只在对话中交付时，给出逐段对照稿，核查说明放在独立说明块。
- 交付时报告英文词数（口径见 journal-style 第 5 节），以及大纲标题被润色或改为美式拼写的位置。
- 不在稿件目录留下处理脚本或缓存；不修改技能目录、全局配置、大纲、图例或数据。

## 交付前检查

- [ ] 散文分号链 0 处（同句 ≥2 个散文分号为 ERROR，结构性分号豁免）；目标平均 18–28 词/句，一般 ≤45 词、硬上限 60 词，>45 词占比 >10% 为 WARN；无连续 ≥3 个 <8 词短句的电报体连跑；WARN 已逐条说明。连接词按逻辑需要使用，不连续三句以上以同一个连接词或短语开头；按 journal-style 的「句长、分号与衔接」复核。

- [ ] 大纲为每节列出的图表都已引用；图号格式为 `(Fig. 2A)`、`(Supplementary Fig. S1)`、`(Table 2)`，中文为全角括号的“图 2A”“补充图 S1”“表 2”；首次引用顺序与编号一致。
- [ ] 每个数字都能在表格、源数据或图注中找到出处，小数位统一；区间、n、P 值写法符合 journal-style 第 2 节。
- [ ] 每个比例都写明了分母集合（真值类扫描、误分类子集、全部预测等），条件方向与源数据一致；行归一化的混淆矩阵比例没有被写成“某类预测的 X%”。
- [ ] 分段与大纲规划一致；段内是连贯散文，没有分点、列表或段内小标题。
- [ ] 核心 panel 按“结果—对比—例外或异质性—证据含义”充分展开，带过性内容简洁；重点突出，没有逐项罗列表格；完整 Results 英文正文达到 3,500–4,000 词，篇幅用于增补有出处的结果细节、跨图关联和研究问题相关含义。
- [ ] 没有绘图方法描述（颜色、线型、图形类型、带宽、轴）、方法复述和内部标识（字段名、文件名、规则代号）。
- [ ] 没有 First、Then、Next、Finally 等机械路标；Moreover、Furthermore、In addition 等按逻辑需要使用，不为凑数堆砌，不连续三句以上以同一个连接词或短语开头；中文同步遵守。
- [ ] 措辞边界逐条遵守：复述一遍大纲每节的“措辞边界”清单，逐条确认正文中有对应表述（含要求强调的限定，如两次分析不可互换），压缩时不得丢失；没有 superior、outperformed 等无检验支持的比较，没有因果化表述；部分类别队列、非独立队列、使用目标标签的参照已如实限定。
- [ ] 关键结果的研究含义及跨图关联有明确证据支持，每段通常不超过一两句；含义限于本研究问题，没有文献对照、临床推广、讨论化、因果外推、复述或宣传性用语。
- [ ] 跨节回指用内容和图号指代，正文没有节号（Section 3.x、“3.4 节”“上一节”）；没有预告后文或设问式衔接句；特别发现用结果句写出，没有 Notably、Interestingly、Importantly、“值得注意的是”等标签词。
- [ ] 限定并入结果句，每项措辞边界每节只表达一次；没有以免责句收尾的段落；not 类免责句不超过 3 次（规则第 5 节）。
- [ ] 段末没有复述句；阐释或综合尾句最多出现在一半段落；therefore／thus／consequently 每节最多一句、全文不超过 6 处；rather than 类并列否定不超过 6 处；没有单独的表格指引句；带过性内容保留了一个具体数字。
- [ ] coexisted、accompanied、separating 等并置词同一个词全文不超过 3 次；表格已列的设备、厂商、来源清单没有在正文逐项枚举。
- [ ] 单 seed、单次或子集分析的口径写在句内；少于 50 个事件支撑的指标已给出 n 或略去；同一舍入值的两个不同量已各自点明口径；跨队列极值已写全。
- [ ] 大纲或图例把差距归因于某一步或某个组件时，已写出整条链上每一步的数值并核对占比；数据只部分支持的，结论和标题已收窄并上报。
- [ ] 句长按 journal-style「句长、分号与衔接」执行；大纲写“见表”“一句带过”的内容没有逐项列数值；每个图号引用的 panel 确实显示该结果。
- [ ] 中英逐段一致，中文按中文语序重组；双语小标题都是陈述发现的句子；美式拼写、缩写首次定义。
- [ ] 核查说明的六项触发已逐项判断，只含规则第 8 节规定的三部分，数字出处表只列需要说明的数字，总长一般不超过两页；未输出时已在交付时说明理由。
