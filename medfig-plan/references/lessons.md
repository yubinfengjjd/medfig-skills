# lessons：规划阶段经验规则

来自一个已完成的医学影像 AI 论文整套图表项目的复盘（编号对应 medfig 经验目录 A / D / E 节）。只保留通用规则，不含项目数据。

## A. panel 规划方法

- A1 一 panel 一结论，先写后画。每个 panel 带 claim 字段；没有 claim 的 panel 拒收。每张图在交付说明里再给一行"科学作用"。
- A2 图型多样性预算。panel 数与版式按论证定，禁止机械 2×2；森林类全套 ≤ 3 处，每处在规格里写理由；其他重复图型同样写理由。
- A3 编码跟数据结构走：x 有序才连线；n 很小画点不画柱；零值不画柱，改点图或删除（不做纯文字 panel，S2）；组间差数量级用 log 轴并画分布；数据撑不起原图型就降级（汇总行 → 区间点，离散取值 → 分组柱，单一交集 → 横向条形）。
- A4 不规则版式在规格标题行声明（panel 数 + 版式一句话），可直接翻译成 GridSpec 与成图尺寸；交付时核对 panel 数，不一致进偏离清单。
- A5 主附图按故事线划分：主图跟主线论证顺序；附图承载每个主结论的细节与稳健性，写明对应关系；次要分析（含阴性）照实放附图或表，按科学问题组织，不按内部计划编号；早期版本丢弃，不当对照（`mainline_rules.md`）；示意图 / 流程图在规格里记为"示意图（外部绘制，本套不出图）"，内容描述只写在规格正文，流水线不渲染任何占位 panel / 图；不打算外部绘制的直接删除并列入偏离（S2）；未做的研究不出图，进不可估计清单。
- A6 影像 panel 选型由数据有效性决定：先查显著图原始量级（接近数值噪声就不展示）；无人工参照时只画预测并标明来源；像素间距无文档依据就不画比例尺；同一病例在不同图中角色不同并互相引用。
- A7 表格：主表 + 附表，每张写明来源；输出 CSV + Markdown + LaTeX + source.json。标配口径裁决表与图表来源索引，后者由 source.json 自动生成、最后重建。
- A8 数据权威先行：规格开头指定一份权威文档，每个有争议的数字写明采用口径；唯一允许的新计算列出且为确定性，记入 provenance。
- A9 主图要让读者一眼看到性能和病例。主图报判别性能时只放点估计、哑铃图，ROC 放附图，读者找不到期刊惯用的曲线；病例影像只放 3–4 例，看起来单薄，也会被质疑挑图。规则：报性能的主图必有 ROC（不平衡加 PR）曲线 panel（S7）；病例影像按组分层、每组 ≥ 12 例、固定 seed 随机并含误判，规则写进图注与 source.json（S6）。

## E. 科学诚信措辞

- E1 禁用词一张表，导出与表格渲染时统一检查：validated、superior、clinical benefit、diagnostic、clinically proven、deployment 等（项目可在 `figkit.toml` 的 `[qa]` 里追加（`banned_extra`，如未使用的降维方法名）或放行默认词（`banned_allow`，如确实使用 UMAP、报告 diagnostic accuracy 的研究））。降维方法名在图上明写，避免误读。
- E2 探索性声明：研究的探索性质只在稿件 Methods 的统计部分用标准写法交代一次；图注、表题不逐图重复，也不写开发流程（wave、closure、修复、口径裁决等，`mainline_rules.md`）。
- E3 图注清单：单位；每组 n 且写明 n 的单位；区间类型与 bootstrap 方式及次数；排除项及计数；估计器细节；小 n 警示；"本图无区间估计"（若适用）；共享病例的交叉引用。
- E4 已知限制在相关处必写：共享组件 → 非独立复现；类别缺失的队列不写成完整多类验证；预测轮廓 → 模型预测非人工标注；汇总派生 panel → 不重建逐样本分布；无横向间距 → 无横向比例尺；上游重采样 → 显示比例 ≠ 原始比例。
- E5 假设措辞：阴性 / 不确定照实报告；设计限制了 P 时给最小可达 P；≤ 与 < 忠实于数值。
- E6 效用 / 不确定性措辞：描述性、不授权临床决策；示例非临床验证；可行性诊断只称诊断；不加用户没要求的规范性句子。
- E7 方法表述追溯到运行产物；上游措辞修正记入口径裁决表并带哈希，注明未改变预测与数值（若属实）。
- E8 偏离全披露：panel 移动、图型降级、尺寸、子标签、示意图外部绘制 / 删除都列入偏离清单与裁决表；未记录的偏离按 Important 处理。

## D. 流程

- D1 规格 → 计划 → 派发：规格先定每个 panel 的结论、数据、编码与限制，状态"待用户审阅"，用户批准后才写实施计划与绘图代码；批准后的改动先回规格。
- D7 主控回源核实：实现者或审查者给出的数字、措辞建议，主控都回到源数据核实后才采纳；规格优先于 brief。

| 自检 | A2, E1–E8 |

- **E12 小多图排版（2026-10-08）**：5 个外部队列 ROC 排成 3 + 2、第二行左对齐、每格重复同一份图例，用户指出右侧留白比左侧多、下排两格很难看；原有的留白检查只看单个 axes 内部，没有拦住。改为 S8：一行排或末行居中、共享图例 + 格内同色数值、与相邻分面 panel 列对齐，并加 `qa.facet_balance` / `qa.repeated_legend` 导出闸门。
